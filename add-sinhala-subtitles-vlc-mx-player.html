How to Add Sinhala Subtitles in VLC, MX Player, Kodi and on a TV

You have a Sinhala SRT file and a video. This guide shows how to load the subtitle in the most common players, and what to do when the letters look wrong or the subtitle does not appear.

SinSubz › Guides

Before you start: three things that avoid most problems

  1. Use a UTF-8 file. Sinhala letters only display correctly when the subtitle is saved as UTF-8. Files made by SinSubz are already UTF-8. If you edit the file, save it again as UTF-8.
  2. Match the subtitle to the video release. A subtitle made for a BluRay release can be a few seconds off for a WEB-DL release of the same film. Pick the release that matches your video, or read how to fix out-of-sync subtitles.
  3. Give both files the same name. If the video is Movie.2025.1080p.mkv, name the subtitle Movie.2025.1080p.srt and keep both in the same folder. Most players then load it by themselves. Players that support several languages also accept a language tag, for example Movie.2025.1080p.si.srt.

VLC on Windows, Mac or Linux

  1. Start the video.
  2. Choose Subtitle → Add Subtitle File… and select the SRT file. You can also drag the SRT file onto the VLC window.
  3. If the subtitle is early or late, press G to show it earlier or H to show it later. Each press moves it by 50 milliseconds, so a few presses fix a small difference.

VLC on Android and iPhone

  1. While the video plays, tap the speech-bubble (subtitle) button.
  2. Choose Select subtitle file and pick the SRT from your downloads folder.
  3. Open the same menu to change the subtitle delay if the timing is off.

MX Player on Android

  1. Play the video and tap the subtitle button on the screen (it looks like a speech bubble).
  2. Choose Open… and select the Sinhala SRT file. Or place it next to the video with the same name and MX Player will find it.
  3. The same menu has a subtitle sync option and size settings. If the text is too small to read on a phone, increase the subtitle size there.

Kodi

Kodi loads an SRT that has the same name as the video and sits in the same folder. You can also open the subtitle menu from the playback controls and choose a subtitle file by hand. The subtitle settings let you change the font size and delay while the video is playing.

Windows players (MPC-HC, PotPlayer and similar)

Drag the SRT file onto the player window, or open the subtitle menu (right-click on the video) and add the file. These players usually remember the subtitle for the next time you open the same video.

TV or USB playback

  • Copy the video and the SRT file to the same folder on the USB drive and keep the same file name.
  • Open the subtitle option of the TV player and choose the file. Some TVs only list subtitles that are exactly named like the video.
  • Older TVs do not have a Sinhala font. If you see squares, the TV cannot show Sinhala text. Play the video from a phone, a computer or a streaming stick instead.

When something goes wrong

I see squares or question marks instead of Sinhala letters

Two different causes. Question marks usually mean the file is not saved as UTF-8: open it in a text editor, choose Save As and select UTF-8 encoding. Empty squares mean the player or device has no Sinhala font. Try another player (VLC works on most devices) or check the player's subtitle font setting.

The subtitle does not appear at all

Check that the subtitle track is switched on in the player, that the file name matches the video if you rely on automatic loading, and that the file really is an SRT (a file ending with .srt.txt will not load). Learn how the format works in What Is an SRT File?

Two subtitles show at the same time

The video already has a built-in subtitle track. Turn that track off in the subtitle menu and keep only the Sinhala one.

The subtitle is a few seconds early or late

Shift it with the player's delay option (G and H in VLC), or fix it once for all players with the Sync tool described in this guide.

Frequently asked questions

Which player is best for Sinhala subtitles?

VLC is the safest choice because it runs on Windows, Mac, Linux, Android and iPhone and shows Sinhala text when the file is UTF-8. MX Player is popular on Android phones.

Can I use the same SRT file on my phone and my TV?

Yes, the file is the same. The difference is the player: some TV players cannot display Sinhala letters, even with a correct file.

Do I have to rename the subtitle file?

No. You can also pick the file from the player menu. Renaming it to match the video only makes the player load it automatically.

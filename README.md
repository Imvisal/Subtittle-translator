# 🎬 SubLanka AI

### English → Sinhala Subtitle Translator

SubLanka AI is a web-based subtitle translation tool designed to help users find, upload, translate, and download subtitles in Sinhala.

---

## ✨ Features

- 🎬 Search for movie subtitles
- 📺 Search for TV series subtitles
- 🔎 Find English subtitles
- 📁 Upload `.srt` subtitle files
- 🇱🇰 Translate English subtitles into Sinhala
- 👀 Preview subtitle content
- ⬇️ Download translated Sinhala subtitles
- 🌐 Responsive design for desktop and mobile
- ⚡ Fast and simple interface
- 🔐 Server-side API integration

---

## 🛠️ Technologies

| Technology | Usage |
|------------|-------|
| HTML | Website structure |
| CSS | UI and responsive design |
| JavaScript | Application functionality |
| SubDL API | Subtitle search |
| OMDb API | Movie & TV information |
| Translation API | Subtitle translation |
| Vercel | Deployment |

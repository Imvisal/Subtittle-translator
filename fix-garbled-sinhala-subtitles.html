Sinhala Subtitles Showing Boxes or Strange Symbols? How to Fix It

You downloaded a Sinhala subtitle, loaded it in your player, and instead of Sinhala letters you see squares, question marks or strange symbols. This almost always comes from one of a few causes, and each one has a simple fix.

Fix 1: the font has no Sinhala letters (squares)

Every player draws subtitles with a font. If that font does not contain Sinhala, you get squares. Change the subtitle font to one that does, such as Noto Sans Sinhala, Iskoola Pota or Nirmala UI (Windows). The setting is in the subtitle or text options of the player:

  • VLC: Tools → Preferences → Subtitles/OSD → choose a font that supports Sinhala. Menu names can differ a little between versions.
  • MX Player: Settings → Subtitle → look for the text or font options and choose a custom font.
  • Kodi: Settings → Player → Language → set the subtitle font to a Unicode font that supports Sinhala.

On Android and Windows, the system already has a Sinhala font in most versions. On older devices it may be missing, and installing Noto Sans Sinhala is the simplest fix.

Fix 2: encoding (question marks or strange characters)

A subtitle file is text, and the player must read it with the same encoding that was used to save it. Sinhala needs UTF-8. If the player reads it as another encoding (for example Windows-1252), the letters turn into nonsense.

  1. Open the SRT in Notepad (or any text editor). If the Sinhala looks correct there, the file itself is fine.
  2. Choose File → Save As, and set Encoding to UTF-8. Keep the .srt extension.
  3. In your player, set the subtitle text encoding to UTF-8 as well. In VLC this is under Preferences → Subtitles/OSD → "Default encoding".

If the file looks wrong even in Notepad, it was saved with a different encoding or was damaged. Download it again.

Fix 3: joined or misplaced letters

Sinhala is a complex script: some letters change shape or combine with each other. Modern players like VLC and MX Player usually draw this correctly. Some older players, built-in TV apps and cheap media boxes do not, and you may see letters that look wrong or separated. If only one device does this, the player is the problem, not the subtitle. Try another player app on the same device, or play the video from another device.

Fix 4: no subtitle appears

  • Put the subtitle in the same folder as the video and give it exactly the same file name, for example Movie.mkv and Movie.srt.
  • Turn the subtitle on from the player's subtitle menu. Some players show nothing until you select the track.
  • On a TV, copy both files to a USB stick and use the TV's built-in player. If your TV does not support Sinhala, use a media box or a phone cast.

The steps for each player are in how to add Sinhala subtitles in VLC, MX Player, Kodi and on a TV.

Prevent the problem next time

  • Always use an SRT file saved as UTF-8. See SRT, VTT and ASS: which format should you use for why SRT is the safest.
  • Avoid ASS files for Sinhala unless you know the style and font settings inside them.
  • If the subtitle is correct but the timing is off, see how to fix out-of-sync subtitles.

Frequently asked questions

Why do I see boxes instead of Sinhala letters?

The font used by the player does not include Sinhala. Choose a font that supports Sinhala, such as Noto Sans Sinhala, in the subtitle settings.

Why do I see question marks or strange characters instead of Sinhala?

The file is being read with the wrong encoding. Save the SRT as UTF-8 and set the player's subtitle encoding to UTF-8.

The subtitle looks fine on my phone but broken on my TV. Why?

TV players often have limited font and complex-script support. Try a different player app, a media box, or watch from another device.

Do I need to download the subtitle again?

Only if it looks wrong even when you open it in Notepad. If it looks correct there, the problem is the player's font or encoding setting.

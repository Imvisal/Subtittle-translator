Where to Find English Subtitles for Movies and TV Shows

Before you can get a Sinhala subtitle, you usually need an English one. Finding the right file is more important than most people think: a subtitle made for a different version of the video will drift out of sync no matter how well it is translated.

Where English subtitles come from

  • The video itself. Many MKV and MP4 files already contain English subtitle tracks. Open the file in a player such as VLC and check the subtitle menu before you download anything.
  • Streaming services. Most services let you turn on English subtitles while you watch. This is for watching on that service; taking subtitles out of protected streams is not something we cover or recommend.
  • Community subtitle sites. Volunteers upload subtitle files for new and old titles. Sites such as OpenSubtitles and SubDL are well known examples. Availability and rules change, so check each site's own terms.
  • SinSubz search. On SinSubz you can search for a movie or series, pick one of the English subtitles that were found, and translate it to Sinhala in one go.

How to choose the right file

For popular titles there are often many files. Look at these details before you download:

  • Release name. Video files have names like Movie.2024.1080p.WEB-DL or Movie.2024.BluRay.x264. Pick a subtitle whose release name matches your video. A subtitle made for a BluRay release often does not match a WEB-DL release.
  • Frame rate. If the subtitle drifts further out of sync as the movie goes on, the frame rate differs. Choose another file instead of fighting with the timing.
  • Hearing-impaired (HI or SDH) versions. These include sound descriptions like [phone ringing]. They are useful for deaf viewers but can be noisy for everyone else. A normal version is better if you plan to translate.
  • Upload date and download count. A file with many downloads and good comments has usually been checked by other people.
  • Completeness. Check that the file covers the whole video, not just the first part. For TV, make sure the season and episode numbers match.

Stay safe when you download

  • A subtitle is a text file. The common formats are .srt, .vtt and .ass. Subtitle sites often give you a .zip, which only needs to contain a text file inside.
  • Never run an .exe, .msi or .apk file that claims to be a subtitle or a "subtitle downloader".
  • Be careful with pages that cover the download button with several fake ones. Look for the real file name and size.
  • Do not give out passwords or personal information to download a subtitle.

Check the file before you translate

  1. Open the file in a text editor and confirm that the text is English and readable, not strange symbols.
  2. Check that the first lines look like normal SRT blocks (a number, a time line, then text). See what is an SRT file.
  3. Play the first few minutes with the subtitle. If the times are already wrong, fix the sync or try another file.

Frequently asked questions

Can I use an English subtitle that was made for a different release of the movie?

You can, but it often goes out of sync. It is better to pick a subtitle whose release name (such as WEB-DL or BluRay) matches your video.

What does SDH or HI mean on a subtitle?

It means the subtitle is made for deaf or hard-of-hearing viewers and includes sound descriptions such as [music playing]. If you want a clean translation, a normal version is usually better.

Is it safe to download a subtitle zip file?

A real subtitle zip contains only a text file such as .srt. Never run an .exe, .msi or .apk file that is offered as a subtitle.

Does SinSubz host movies?

No. SinSubz only works with subtitle text files. You need to get your own video legally.

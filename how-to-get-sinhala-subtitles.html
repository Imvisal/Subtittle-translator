How to Get Sinhala Subtitles for a Movie or TV Series

You have a movie or an episode and only English subtitles exist? Here is the quickest way to turn them into Sinhala subtitles and watch with them on your phone, PC or TV.

SinSubz › Guides

Option 1: search for the movie or series

  1. Open SinSubz and type the name of the movie or TV series in the search box.
  2. Pick the title from the results. For a TV series, choose the season and episode.
  3. SinSubz lists the English subtitles that are available. Choose one that matches your video release (for example the same 1080p or WEB-DL release name as your file).
  4. Press Translate. The AI translates the dialogue into natural, spoken Sinhala. Long films take a few minutes, and you can follow the progress on the screen.
  5. When it finishes, download the Sinhala SRT file.

Option 2: upload your own SRT file

If you already have an English SRT file, use the Upload tool: choose the file, start the translation and download the Sinhala version when it is ready. SinSubz keeps the timestamps and translates only the text.

Load the Sinhala subtitle in your player

  • Same name trick: put the SRT file in the same folder as the video and give it the same file name (for example Movie.2024.1080p.mkv and Movie.2024.1080p.srt). Most players load it automatically.
  • VLC: Subtitle → Add Subtitle File…, then choose the SRT file.
  • Phone and TV players: most have a subtitle button or menu where you can pick a subtitle file. Make sure the file is saved as UTF-8 (SinSubz does this for you) so the Sinhala letters show correctly.

If the subtitle is early or late

The timing of an English subtitle can differ between video releases. Read how to fix out-of-sync subtitles: you can sync the Sinhala subtitle to your exact movie file with the SinSubz Sync tool.

Tips for better results

  • Choose an English subtitle that has complete sentences and few spelling errors. The translation can only be as good as the source.
  • Read the first few minutes after translating. If a line sounds odd, you can edit the SRT in any text editor.
  • Use the same release for the subtitle and the video whenever you can.

Frequently asked questions

Do I need to install anything?

No. SinSubz works in your browser. There are also an Android app and a Windows app on the download page.

Which subtitle file type works?

SRT files. This is the most common subtitle format and almost every video player supports it.

What Is an SRT Subtitle File?

SRT (SubRip Text) is the most widely used subtitle format. It is a plain text file with a .srt extension, which is why you can open it with Notepad and why almost every video player understands it.

How an SRT file looks

Every subtitle is a numbered block with a start and end time, followed by the text:

1
00:00:01,000 --> 00:00:04,000
Hello, how are you?

2
00:00:05,200 --> 00:00:08,000
I am fine, thank you.
  • The number is the order of the subtitle.
  • The time line shows when the subtitle appears and disappears: hours:minutes:seconds,milliseconds.
  • The text can have one or two lines. A blank line ends the block.

SRT and Sinhala text

Sinhala letters need the file to be saved with UTF-8 encoding. If a Sinhala subtitle shows strange symbols or boxes in a player, the encoding is usually the problem. Subtitles downloaded from SinSubz are saved in UTF-8 so they display correctly.

How to open and edit an SRT file

  • Open it with any text editor, such as Notepad on Windows.
  • Change the text of a line if you want to fix a word. Do not change the structure (numbers, time lines, blank lines).
  • Save the file as UTF-8 and keep the .srt extension.

How to use an SRT file

Put it next to your video with the same file name, or add it from the subtitle menu of your player. The full steps are in how to get Sinhala subtitles for a movie or TV series.

Frequently asked questions

Can I open an SRT file on my phone?

Yes. Any text editor app can open it, and most video apps can load it as a subtitle.

Why does my Sinhala subtitle show boxes or symbols?

The file is probably not saved as UTF-8, or the player is using a font without Sinhala letters. Save the file as UTF-8 and try a different player or font setting.
